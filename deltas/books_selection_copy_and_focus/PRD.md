# Books 自动复制取词与窗口前置

状态：需求文档已就绪；用户已进一步授权交给一个 OpenCode Session 实现和测试。入口与执行状态见 [索引](../INDEX.md)。

## 目标与来源

保留 Apple Books 的阅读、中文脚注、阅读位置和手机同步，在原书划选后准确带入文字并解释。解决现有的非空错词、全屏后空选区，以及窗口持续挡住其他应用的问题。

来源：当前任务中用户明确澄清窗口应在划词后前置、点击其他应用后可以被遮挡；理解自动复制可能影响剪贴板后，要求先完成文档。随后讨论文档职责并授权把实现交给一个 OpenCode Session 写代码、测试。本次授权取代此前“本轮先不写代码”的阶段限制；不包含 Git 提交、发布、全局配置变更或长期文档回灌。研究线索见 [全局划词调研](../../../../contexts/survey_sessions/macos_global_text_selection_survey_20260918.md)，其未经实测的推断不视为验收结论。

## 已确认的交互与范围

1. 用户只需在 Books 划词，无需手动 ⌘C、粘贴、快捷键或额外确认。允许程序自动借用 Books 的复制操作取词，但必须实施下述剪贴板保护。
2. 新选区进入现有问答窗口；自动解释开启时按已保存模板发送，关闭时只带入文字。关闭自动解释不等于停止取词，也不等于后台完全不使用剪贴板。
3. 划词后窗口一次性到前面来，方便阅读与输入。用户点击 Books 或其他应用后，窗口让出前面的位置，其他窗口可遮挡它；未出现新选区时，回答流式更新、轮询或重试均不得再次抢前面的位置。
4. 点外部不等于关闭、清空或取消对话；保留已读结果和输入。全屏需要同样的交互效果，但仅在真正实测通过后声明支持。
5. 同一次有效选区最多启动一次自动解释。无选区、复制失败、超时或结果有歧义时，不用旧词或猜测文本发请求；已有对话保留，并给出简短失败状态。

## 剪贴板的产品合同

- 正常事务结束后恢复操作前的剪贴板，包括可完整保存的图片、富文本等类型，不能只备份纯文本。无法完整备份时跳过复制并说明取词失败，不冒险覆盖。
- 如果用户或其他应用在此期间复制了新内容，优先保留新内容，不强行恢复旧快照。
- 原有剪贴板内容仅在内存暂存，不写日志、词本、文件或模型请求；Books 本次选区仍按已有规则保存与发送。
- 不承诺零污染。剪贴板历史工具可能记录临时文字，系统通用剪贴板可能传播文字；异常退出也可能来不及恢复。用户已在获知这些限制后允许按本方向准备 Delta，仍需实测正常操作的干扰程度。
- 本 Delta 不改变系统同步设置或其他剪贴板工具的配置，也不以后台恢复为由宣称这些外部副作用已经消除。

## 不变量与非目标

保留现有 Swift 原生应用、500×539 默认尺寸、只竖向滚动、收起的提示词编辑器、用户保存的音标版模板、自动解释开关、连续追问、词本与持续日志。模型继续使用本机已有 LiteLLM Gemini Flash 配置，除 API 外不增加软件费用。

本次只适配 Apple Books。全局划词、自建阅读器、手机端、OCR、重新设计界面、重做签名分发、添加第二个取词开关均不在范围内。不修改原书、标注、Books 数据库、系统快捷键或其他应用配置。

## 与旧文档的关系和待验证项

旧 `docs/prd.md` / `docs/rfc.md` / README 的“不使用剪贴板、不合成按键”描述当前安装版。本 Delta 明确把用户无需手动复制与程序允许自动复制区分开；新合同尚未回灌长期文档。

尚待验证的是技术可行性：Books 的复制结果能否覆盖故障现场，是否扰动原生选词弹窗，以及全屏时能否实现一次前置后让出。若必须增加用户操作、改变阅读习惯或扩大权限/范围才能继续，应先更新本 Delta 并向用户说明，不能默默降低验收要求。
