# 阅读浮窗收起交互与模型速度比较

来源：2026-09-20 用户在已安装右上角定位版本上反馈：点其他 App 时可回到阅读，但点击 Apple Books 不能快速收起窗口；希望点击浮窗区域外即可收起，并要求讨论合理交互。另要求用当前 Prompt 对 Gemini 3.7 Flash、3.5 Flash、DeepSeek V4 Flash 各测五组。用户随后明确排除 Max，因此不调用网关唯一的 4.1 Max。

## 已确认范围

- 保持 Apple Books 阅读体验，查完词可点击浮窗区域外快速收起，包括图书正文和空白区域。
- 09-20 用户已确认交互方案并授权实现、测试、更新本地应用；新增可勾选的「15 秒后自动收起」，默认关闭并持久化。模型比较已完成。
- 用当前已保存的 Prompt、真实上下文匹配逻辑和请求参数，测试两组单词、一组短语、两组短句。核对首段正文出现时间、完整返回时间、英文遵循情况和表达格式。
- 不擅自切换当前使用的模型；不修改用户保存的 Prompt。

## 实施前事实

实施前安装版对应 `src/main.swift` SHA-256 `3950a0569624c03ca3507fce6328d55cd6332e382328fba883a9bc89be7fde4f`。窗口为 `.normal` 层级、`hidesOnDeactivate=false`，并使用 `.nonactivatingPanel`；Esc 已调用 `orderOut`。鼠标监听用于 Books 手势，没有区域外点击隐藏逻辑。此前的“按窗口顺序退让”并不等价于本次希望的“区域外点击收起”。

## 已确认交互与本轮实现范围

1. 新选区采集完成后，按划词松开时的位置显示在另一侧：Books 窗口右半边划词 → 所在屏幕左上角；左半边划词 → 右上角。保持原尺寸和自动解释开关。没有划词位置的显式打开使用右上角；恢复已有对话沿用该次划词的方向。
2. 点击浮窗以外的位置立即收起，包括 Books、其他应用、桌面；原点击继续传给目标，不消耗一次点击。Esc 同样收起。
3. 收起保留当前对话和未发送输入，不退出、不关闭自动解释。未完成回答继续在后台生成并保存，结束时不重新显示。
4. 点击浮窗内部、编辑提示词、选择/滚动回答不触发收起。指针只是移出或用户仅滚动图书不触发收起。
5. 单击继续阅读不得因为旧选区仍存在而再次弹出或重新扣费。下一次真实划选才显示；显式从菜单打开也可恢复当前对话。

6. 同词通过新的真实划选捕获后，恢复现有对话与未发送输入，不重新请求模型；旧轮询不会触发这个分支。
7. 顶部增加「15 秒后自动收起」复选框，默认关闭，记住设置。勾选后，新选区弹出起计 15 秒；主动打开已有对话不启动计时。窗口显示期间刚勾选则从此刻计时。超时仅隐藏，后台请求照常进行。新选区重计 15 秒，关闭选项立即取消待执行计时。
8. 已向用户询问计时中操作浮窗的偏好；当前推荐默认：点击、输入或滚动浮窗取消本次计时，下次划词重新计时。只移入指针不取消。若用户另有回复按其选择调整。

## 可观察验收

分别点击 Books 正文、空白、桌面和其他 App，窗口均隐藏且目标收到同一次点击；浮窗内部操作不隐藏；Esc 可隐藏；隐藏后模型完成不重新弹出且结果入词本；随后新拖选可重新弹出并关联正确选区；后台轮询不能把旧选区重新显示。对普通窗口及 Books 原生全屏分别验证，真实 UI 验收不能用 API 测速替代。

本轮模型测试方法、完整输出和结果统一见 [TEST.md](TEST.md)。

## 鼠标位置决定避让方向（后续确认）

用户随后指出，划词松开时鼠标的位置已足够决定方向，不需要识别实际栏位。此确认取代本轮最初暂缓换边的结论。以 Books 窗口中线为界；窗口边界不可用时以鼠标所在屏幕中线为界。不识别单双栏、边栏或文字语义，不引入 OCR 或模型调用。

记录原始 mouse-up 事件中的坐标，与同次 captureID 一起经过复制等待和异步取词。后续鼠标移动、API 延迟不改变这次展示方向；新划词更新方向。失败或被新手势替代的旧结果不得改变方向。新的真实手势重新选择同词时，允许换边并恢复已有对话，仍不重复请求模型。
