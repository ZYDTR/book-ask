# 实现与边界

旧WordbookStore从history.jsonl按书名+忽略大小写/压缩空白分组，并显示每次visit；receive每次触发ask，未查词本。

新增版本化wordbook.json，精确term键与单一WordbookEntry，包含来源书名、一份初始完整解释及去重后的主动追问。串行actor负责加载/查询/保存，原子替换文件，首次从旧history导入前私有备份。history继续保存选区、缓存命中、模型请求等审计事件，不作为迁移后的词本展示数据。失败读取不当作缓存未命中，避免误发付费请求；损坏词本原样保留并报错。取消和半截流不写成成功答案。

主窗先查词本，再决定是否自动请求；用selection revision阻止旧异步查询覆盖新选区。缓存回答恢复对话消息，主动追问继续同一词条。完整模型回答须先持久化再显示已完成；词本写失败有诊断且不覆盖旧文件。同一选区正在生成时重复触发保留当前请求。所有命中/未命中/写入/迁移错误有日志，不输出密钥。

验证用隔离目录、临时UserDefaults/本地URLProtocol拦截模型请求，不污染真实词本；精确相等、跨书、重启、已有失败、空发送、手动追问、切换中的旧查询和保存失败分别检查。安装后核对真实历史清理数量及原生词本，真实Books手势与模型调用另记，不能用测试样例冒充。
