# 精确词条复用

2026-09-20 用户指出重复查询只是在词本里分组，没有避免模型调用。要求完全相同的term永远只有一个词条，再次划到直接复用已有解释，并清理旧重复记录。

以交付到应用的原文（沿用去首尾空白）作为词条身份，保留大小写、内部空白和标点，不按书籍另建相同term。已有完整回答时，无论自动解释开关如何、应用是否重启，直接显示本地词条；输入框留空发送也复用。主动输入追问仍可调用模型并保存到同一词条。只有选区而无完整回答的旧记录允许补齐解释，取消、失败或截断文本不作为可复用回答。

词本取消多次划词/多份初始释义的概念。旧数据选取最近一份完整初始解释，并保留去重后的有效追问；较新的失败记录不覆盖已有成功回答。旧原始日志完整备份，作为诊断材料保留，用户词本转为一个term一条的存储。

保留暗色/浅色、Prompt、Gemini模型、500×539窗口、原有取词/剪贴板恢复/浮窗交互。此次授权包含本地实现、可回滚的旧词本清理和用户级安装，不包含Git推送。
