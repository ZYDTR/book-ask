# 需求

保留 Apple Books 中已有中文词汇注释版 The Mom Test，划选短语或句子后直接提问、连续对话，解释表达、语法或作者逻辑。

用户明确指定本地 Repository、先 scaffolding、除模型 API 外免费、使用既有 LiteLLM Gemini Flash，必须通过真实书籍划选和实际 AI 响应验收。2026-09-18 追加：应用开着时不接受 ⌘C 中间步骤，划完即可发消息。

采用免费原生应用与辅助功能选区读取。PopClip 未安装且付费。本机 Books 不显示文本服务入口；复制即问不满足最新要求，已替换。

## 验收

1. 原书真实划选后自动出现提问窗口，无复制粘贴。
2. 输入问题后返回真实 Gemini Flash 答案，并能连续追问。
3. 自动匹配本机 EPUB 前后文，歧义或失败如实提示。
4. 自动解释默认开启：新选区按可编辑模板自动调用模型；关闭后仍显示选区，但不自动发送。模板与开关本地持久保存。
5. 保留原书、已有标注和阅读位置。
6. 仅在已授权时读取 Books 的选区；以新选区变化触发，不把前台应用判断作为门槛；密钥不在仓库、日志或 UI。
7. 默认窗口外框 500 × 539 点；仅竖向滚动，文本自动换行。移除两种解释预设、复制回答和回到图书按钮。
8. 模板先用简单直接的英文解释当前语境的含义，再给同词语/表达/句式的新例句；避免无关类比和多余认知负担。

9. 模板默认收起，通过「编辑提示词」展开编辑，可收起；划选、请求和完整回答保留本机 JSONL 记录，不存 API Key。
